# templates

A collection of reusable templates for various projects and uses.

## Contents

- [src/app-overview-template.md](src/app-overview-template.md) — machine-maintained template for documenting an application's overview, architecture, and components.

## Usage

Copy the relevant template into your project and fill in the placeholders (e.g. `{{FIELD_NAME}}`) as directed by the instructions at the top of each file.
